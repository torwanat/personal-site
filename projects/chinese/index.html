Chinese Game - online implementation of the classic game

Online multiplayer implementation of the classic tabletop game, known also as "Ludo" or "Mensch ärgere dich nicht". The game offers full multiplayer experience, with automatic matchmaking, multi language support and more.

Back to projects overview

Overview

This implementation of the classic board game, sometimes known as "Ludo" or "Mensch ärgere dich nicht" is a web-based multiplayer game that allows 2 - 4 players to compete against each other online. The game features a simple and user-friendly interface, real-time gameplay, and support for both Polish and English language. Players are automatically added to open lobbies, and a game starts as soon as everyone is ready or the lobby is full. During the game, players have 60 seconds to play their turn, or they will be skipped. Players session is automatically saved, so they can return to the game later if they need to leave. To win the game, a player must move all of their pieces from the starting area to the home area before their opponents do.

Tech stack and architecture

The project is a full-stack web application built using Angular for the frontend, PHP for the backend, and MariaDB for the database. The application is containerized using Docker, allowing for easy deployment. The architecture follows a client-server model, with the frontend communicating with the backend via RESTful APIs. The backend handles game logic, user authentication, and database interactions, while the frontend provides a responsive and interactive user interface for players to enjoy the game.

Implementation details

The implementation of the game involved overcoming several technical challenges.


Translation

To provide a seemless experience for players in different languages, the game was designed to support multiple languages. The implementation uses the Gettext library for PHP to handle translations on the backend, while Angular's built-in i18n support is used for the frontend. This allows for easy addition of new languages and ensures that all text in the game is properly translated based on the user's language preference.


Remembering users session

To enhance the user experience, the game was designed to remember users' sessions. This means that if a player leaves the game and returns later, they can pick up where they left off without losing their progress. This was achieved by storing session data in the database and using cookies to identify returning players. When a player returns to the game, their session data is retrieved from the database, allowing them to continue playing seamlessly.


Containerization

To simplify deployment and ensure consistency across different environments, the game was containerized using Docker. This allows the entire application, including the frontend, backend, and database, to be packaged into containers that can be easily deployed with Docker Compose. This approach also makes it easier to manage dependencies and ensures that the application runs consistently across different environments.
