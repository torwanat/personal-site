Recording App - an Android app for audio recording, camera capture and photo management.

Built with Kotlin and Jetpack Compose, the app demonstrates microphone recording, CameraX photo capture, and a gallery for viewing and deleting saved images.

Back to projects overview

Overview

Recording App is a small Android application built with Kotlin and Jetpack Compose. It brings together three common mobile-device capabilities: recording and playing back audio through the microphone, capturing photos with the device camera, and browsing or deleting photos saved by the app. The interface is organized into three screens—Audio, Image, and Gallery—connected with Compose Navigation.


  • Areas: Android development, Mobile UI, Multimedia
  • Tech: Kotlin, Jetpack Compose, CameraX, MediaRecorder
  • Status: Active project on GitHub

Tech stack and architecture

The application follows an MVVM-style structure, using ViewModels and Kotlin StateFlow to keep UI state separate from screen composables. Navigation between the Audio, Image, and Gallery screens is handled with Jetpack Compose Navigation. Audio capture uses Android’s MediaRecorder, while playback uses MediaPlayer; camera functionality is implemented with AndroidX CameraX, and images are loaded in the gallery with Coil Compose.

Audio recording

  • Request microphone permission
  • Start and stop recording
  • Play back the latest recording
  • Show active recording or playback state
  • Record to a temporary 3GP file using MediaRecorder

Camera and gallery

The Image screen provides a live CameraX preview and captures photos with the rear camera. Captured JPEG images are saved to the device media store under Pictures/RecordingApp. The Gallery screen loads those images, displays them in a grid with Coil, and allows individual photos to be deleted.

Permissions and compatibility

The app requests RECORD_AUDIO for microphone recording and CAMERA for the preview and photo capture. It targets Android 14 (API 34) or newer, with a minimum SDK of 34 and target SDK of 36. A device with a camera and microphone is required for full functionality.


Build and release automation

GitHub Actions builds a debug APK on pushes to main, pull requests targeting main, and manual workflow dispatch. Release APKs are built and signed through a separate workflow when a v* tag is pushed; signing credentials are supplied through GitHub Actions secrets rather than stored in the repository.
